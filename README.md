# lexicon.realm.watch

Names and the changing of names. The third realm.watch tool — works alongside [clock](https://github.com/jphein/clock.realm.watch) (cache invalidation) and [realm-sigil](https://github.com/jphein/realm-sigil) (deterministic build-time naming) to handle the runtime naming surface and project-rename workflow.

> Status: v0.1 in development. See `docs/superpowers/specs/2026-04-26-lexicon-design.md` for the design.
