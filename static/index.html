The third tool

There are two hard things in computer science: cache invalidation and naming things. clock.realm.watch handles the first at the prompt seam — current time, injected when the model needs it. realm-sigil handles the second at build time, deterministically, from a git hash.

Lexicon is what you reach for when the two collide — when an existing project has been renamed and the old name has been cached in a thousand places. It is also the daily roller for ad-hoc names (agents, branches, entities) and the canonical word library that the rest of the family consumes.
